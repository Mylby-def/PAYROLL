# Система расчётных листов

Веб-приложение для управления расчётными листами преподавателей.

## Структура проекта

- `backend/` - Django REST API
- `frontend/` - React приложение

## Установка и запуск

### Backend

```bash
cd backend
pip install -r requirements.txt
```

**Запуск с выбором БД** (рекомендуется):

```bash
python run.py
```

При старте будет предложено:
- **standart** (или **s**) — использовать сохранённую конфигурацию БД (из прошлого запуска);
- **new** (или **n**) — ввести данные новой БД (SQLite, PostgreSQL или MySQL); конфигурация сохранится в `db_config.json`.

После первого выбора «new» при следующих запусках можно выбирать «standart» для использования той же БД.

Классический запуск без выбора БД (по умолчанию — SQLite `db.sqlite3`):

```bash
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## Функционал

- Создание и управление расчётными листами
- Управление преподавателями, предметами, группами
- Настройка тарифов (за час, за группу)
- Управление премиальными
- Экспорт расчётных листов в Excel
- Отправка отчётов

## Роли

- **Пользователь** - может создавать и отправлять расчётные листы
- **Бухгалтер** - может управлять тарифами, премиальными и утверждать расчётные листы
